## Sobre este repositorio

Este portfolio es una web estática de un solo archivo (`portfolio-agustin-marquardt.html`), construida con **HTML, CSS y JavaScript vanilla**, sin dependencias ni build. Incluye:

- Diseño responsive y modo bilingüe (ES / EN) con toggle.
- Animaciones de reveal on scroll y mockup de teléfono interactivo.
- Tipografías: Syne, Manrope y JetBrains Mono.

### Cómo verlo localmente

Abrí el archivo directamente en el navegador:

```bash
open portfolio-agustin-marquardt.html
```

O serví la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
# luego abrí http://localhost:8000/portfolio-agustin-marquardt.html
```
